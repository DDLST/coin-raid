# Refactor RAID COIN into gameplay systems

В версии 10 игровая логика была сосредоточена в большой GameScene, а вспомогательные модули лежали в одной папке. Код разделён по игровым системам; сцена связывает их и задаёт порядок кадра. Герой, мир, путешествие, интерфейс и графика имеют отдельные группы состояния. Добавлена карта проекта с поиском, просмотром исходников и переходами к конкретным символам.

Сохранены игровые правила, формат ручного сохранения, ассеты и лицензии. Параметры всех сочетаний враг–биом сравниваются с результатом исходной v10. Удалены 96 служебных файлов Zone.Identifier, обновлены готовые сборки, добавлены форматирование, проверки и workflow для push/PR.

Проверка: `npm run verify`, `npm run test:browser`. Тесты покрывают правила боя и развития, старое сохранение, интерфейс, магазин, смерть и обучение, варианты атак всех боссов, запуск сборок в подпапке и автономный file:// без HTTP-запросов. Проверены поиск и переходы карты исходников. Полное прохождение обычным игроком и баланс сложности отдельно не оценивались.
