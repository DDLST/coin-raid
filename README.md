# RAID COIN - Осколки души

Браузерная игра для компьютера с клавиатурой и мышью. Версия 10.2.0.

Дракон похитил семью лиса и запер её за восемью печатями. В каждой заражённой области призрак разрывает связь героя с оружием. Собери осколки души, верни духовный клинок и победи хозяина печати.

## Как проходит путешествие

На начальном экране можно включить обучение. После практики герой остаётся в безопасном предбиоме; стрелка и карта показывают дорогу к первой роще. Историю и сцену похищения оружия можно пропустить.

В биоме нужно накопить указанную силу и победить босса. Враги предсказывают движение, обходят препятствия и появляются до победы над хозяином. У каждого из восьми боссов три собственных многоступенчатых приёма, которые не используются обычными врагами. На половине здоровья начинается вторая фаза.

Кровавый индикатор показывает квоту осколков до пробуждения. Для последних десяти осколков появляются короткие исчезающие цифры со звуком сердцебиения. При появлении босса слышен крик. Красные линии и метки показывают точные опасные зоны; у колец безопасна середина. Перекат позволяет избежать удара. Физические атаки можно парировать по направлению к атакующему; магические печати требуют уклонения.

После смерти босса оставшаяся нежить его биома рассыпается и выдаёт обычную награду. Награда босса и искра мастерства выдаются один раз. Когда собрана нужная сила, туман уходит, вместо могил появляются цветы, а дороги открываются. Очищенные области можно посещать снова. После освобождения семьи доступно свободное исследование всего очищенного мира.

В деревнях стоят дома кузнеца, бронницы, лекаря и странника. В каждый дом можно войти на E. Жители разных поселений имеют собственные имена, облик, диалоги и ассортимент. Костёр последней посещённой деревни возвращает героя после смерти. Покупки и деньги остаются в текущем путешествии; сундуки испытаний непройденного биома обновляются после смерти.

## Управление

| Кнопка         | Действие                                           |
| -------------- | -------------------------------------------------- |
| WASD / стрелки | Движение                                           |
| Мышь           | Направление оружия                                 |
| ЛКМ / J        | Атака, комбо, контрудар после точного парирования  |
| ПКМ            | Второй приём оружия; у меча - парирование          |
| C              | Парирование физического удара спереди              |
| Пробел / Shift | Перекат                                            |
| Q / V          | Фляга / купленное зелье                            |
| 1, 2, 3 / R    | Изученные приёмы / абсолютное умение               |
| E              | Разговор, дверь, сундук, предмет задания           |
| Tab / Esc      | Инвентарь, навыки, дневник, настройки и сохранение |
| M / H / P      | Карта / убираемая справка / пауза                  |

Во время боя на экране остаются жизненные показатели, сила, таймер и необязательная полупрозрачная справка. Кошелёк, вещи, карта, задания и настройки находятся в меню.

## Развитие героя

Шесть рисованных оружий имеют разные радиусы, темп, расход выносливости, комбо и абсолютные атаки. Кисти держат оружие за измеренные точки хвата; у копья и секиры используется хват двумя руками. Замах, удар, возврат, бег, перекат, парирование и навыки имеют отдельные позы. Точный блок открывает мощный контрудар по отмеченному врагу.

У лекаря доступны повторные улучшения здоровья и выносливости: +10 за 100 осколков, затем за 150, 200 и далее. Каждая характеристика имеет свою растущую цену. Можно покупать дополнительные зелья. Противники продолжают приносить деньги, даже если ограниченный доход от осколков на земле уже исчерпан.

Боссы и доставки дают искры для веток умений. Изученные приёмы можно убирать с панели и возвращать вложенные искры без повторной оплаты. Сюжетные поручения записываются в дневник и отмечаются на карте. Испытания дают сундуки со случайной наградой; вероятность пустого сундука показана в игре. Достижения отмечают прогресс исчезающими сообщениями.

Дождь создаёт мокрые зоны, гроза бьёт по отмеченной точке, метеоры поражают героя и врагов, ураган затягивает обоих в свой центр. Музыка меняется по области и ситуации; в бою с боссами используются металлические композиции. Все записи и ассеты включены в проект; авторы и лицензии приведены в ASSET_CREDITS.md.

## Сохранение

Автосохранения нет. Новая игра всегда начинается с нуля. Сохранить или загрузить ранее вручную записанный путь можно в меню путешествия. Перед выходом из несохранённой игры появляется предупреждение; системный диалог браузера может иметь собственный текст.

## Запуск готовой игры

Распакуй весь архив и открой `PLAY.html` двойным щелчком. Папка `play/` должна оставаться рядом: в ней находятся движок, изображения и музыка. Подключение к интернету для этого запуска не требуется.

`docs/` содержит сборку для GitHub Pages и обычного HTTP-сервера. Файл `index.html` в корне предназначен для разработки через Vite. [guide/index.html](guide/index.html) - отдельный справочник по исходному коду, его также можно открыть двойным щелчком.

## Разработка

Нужен Node.js версии 20.19 и новее. Установка и запуск:

```sh
npm ci
npm run dev
```

Открой адрес из вывода Vite. `package-lock.json` фиксирует версии зависимостей; изменение архитектуры не требует обновлять Phaser, TypeScript или Vite.

| Команда                  | Назначение                                              |
| ------------------------ | ------------------------------------------------------- |
| `npm run dev`            | Сервер разработки                                       |
| `npm run typecheck`      | Строгая проверка TypeScript                             |
| `npm run build`          | Сборка Vite в `dist/`                                   |
| `npm run preview`        | Просмотр `dist/` через HTTP                             |
| `npm run build:offline`  | Обновление `docs/`, `PLAY.html` и `play/`               |
| `npm run format`         | Форматирование исходников и документации                |
| `npm run format:check`   | Проверка форматирования                                 |
| `npm run docs:map`       | Обновление HTML-справочника и индекса исходников        |
| `npm run docs:map:check` | Проверка, что справочник соответствует исходникам       |
| `npm run verify`         | Форматирование, типы, сборки и актуальность справочника |

После изменения кода:

```sh
npm run format
npm run docs:map
npm run verify
```

`verify` пересобирает готовые комплекты. Файлы внутри `docs/` и `play/` не редактируются вручную.

## Где менять игру

Все общие константы и таблицы находятся в [src/game/Constants.ts](src/game/Constants.ts): параметры героя, врагов, биомов, волн, атак, навыков, цен, погоды, уведомлений, звука, атласов и кадров. Разделы файла подписаны по назначению. Локальные `const` внутри методов хранят результаты вычислений и ссылки на текущие объекты.

| Что требуется изменить                       | Файл или раздел                                                                                                      |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Начальное HP, скорость, регенерация, лечение | `Constants.ts`: `PLAYER_CONFIG`, `DODGE_*`, `FLASK_HEAL`; формулы - `combat/CombatRules.ts`                          |
| Цены, оружие, броню, навыки                  | `Constants.ts`: `ATTRIBUTE_*`, `WEAPONS`, `ARMORS`, `UPGRADES`, `SKILL_TREE`                                         |
| Квоту осколков и характеристики биома        | `Constants.ts`: `REGIONS`                                                                                            |
| Условие появления босса                      | `core/BossAwakeningSystem.ts`: `shouldAwakenBoss()`                                                                  |
| Интервалы и ограничения волн                 | `Constants.ts`: `SPAWN_CONFIG`, `WAVE_*`, `MAX_MINIONS`; поведение - `enemies/EnemySpawnSystem.ts`                   |
| Урон и приёмы обычных врагов                 | `Constants.ts`: `ENEMY_PARAMETERS`, `ENEMY_ATTACK_CONFIG`, `ENEMY_ATTACK_MOVES`; выполнение - `EnemyAttackSystem.ts` |
| Уникальные приёмы и ярость босса             | `enemies/BossPatterns.ts`, `enemies/BossSystem.ts`; параметры - `BOSS_CONFIG`                                        |
| Обычные атаки и абсолютное умение            | `combat/CombatSystem.ts`, `combat/UltimateSystem.ts`; таблицы - `HEAVY_ATTACKS`, `SKILL_ATTACKS`, `ULTIMATE_CONFIG`  |
| Переходы режима и паузу                      | `core/GameStateSystem.ts`, `Constants.ts`: `GAME_TRANSITIONS`                                                        |
| Полный сброс путешествия                     | `core/GameSession.ts`: `reset()` и методы сброса состояний                                                           |
| Сундуки, достижения, задания                 | `quests/LootSystem.ts`, `AchievementSystem.ts`, `QuestSystem.ts`                                                     |
| Показатели героя и окна                      | `ui/HudController.ts`, `MenuController.ts`, `MapController.ts`                                                       |
| Клавиатуру, мышь, кнопки                     | `ui/InputController.ts`                                                                                              |
| Сохранение и проверку JSON                   | `persistence/SaveSystem.ts`, `persistence/SaveSchema.ts`                                                             |
| Музыку по ситуации                           | `audio/AudioDirector.ts`; записи и темы - `Constants.ts`                                                             |
| Загрузку и нарезку изображений               | `rendering/SceneArtwork.ts`, `rendering/textures/`; пути и таблицы - `Constants.ts`                                  |

`GameScene` создаёт системы и задаёт порядок кадра. Режим хранится только в `flow`; временные данные интерфейса - в `ui`; параметры героя - в `hero`; прогресс - в `journey`; объекты мира - в `worldState`. Пауза останавливает обновление мира, а новая сессия сбрасывает состояния через их владельцев.

Пробуждение босса по осколкам и ярость при половине HP - разные переходы. Первый проверяет `BossAwakeningSystem`, второй - `BossSystem`. Неиспользуемое поле `bossTime` удалено из таблицы областей.

Изменение `ULTIMATE_MAX` учитывается при обучении, загрузке и отображении заряда. Дальность абсолютной атаки берётся из `ULTIMATE_CONFIG` и в расчёте попадания, и в отрисовке. `ATTRIBUTE_*` задают цену и прирост, включая тексты магазина. `UI_CONFIG.itemsPerPage` управляет магазином, экипировкой и достижениями. `TUTORIAL_CONFIG`, `TRIAL_CONFIG` и `LOOT_CONFIG` задают обучение, испытания и награды.

Снаряды обновляет `combat/ProjectileSystem.ts`, зоны урона — `combat/HazardSystem.ts`, временную графику — `rendering/CombatEffectRenderer.ts`. `ActorRenderer` вызывает отдельные `HeroRenderer`, `EnemyRenderer`, `ResidentRenderer` и `WorldObjectRenderer`. Чистые правила испытаний и случайных наград разделены между `TrialRules.ts` и `LootRollRules.ts`.

Для численных настроек достаточно изменить соответствующее значение в `Constants.ts`; при добавлении новой механики потребуется её поведение и проверка. Технические координаты рисунков и промежуточные вычисления остаются в своих методах.
